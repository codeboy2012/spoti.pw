This project

What PwEevee actually contributed

PwEevee did not create any of the above. Its contribution is integration, build, packaging, testing, hosting and distribution:

  1. one unified build pipeline and dependency resolver — duplicates fail the build
  2. Mach-O load-command injection and the validation suite around it
  3. byte-exact Debian packaging generator with automated format tests
  4. deterministic IPA packager and build manifests
  5. this website, its documentation, and the GitHub release automation behind it

Maintained by one developer. See Development for how the work is done.
