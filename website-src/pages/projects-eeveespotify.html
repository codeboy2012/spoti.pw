Inside a build

How this component is used

What ships

PwEevee installs the payload from the upstream deb as Frameworks/EeveeSpotify.dylib together with the Orion.framework and EeveeSwiftProtobuf.framework it depends on, the EeveeSpotify.bundle resource bundle, and 142 custom app icons placed at the app root where the icon picker reads them.

The exact package version integrated in each build is recorded in that build's manifest and shown on the download.

Three version numbers, three sources

The package version integrated in a PwEevee build, the newest GitHub release in the upstream repository, and the EeveeSpotify version named by a SideloadLabs AltSource variant are three separate facts. All three appear on this site, each labelled with where it came from, rather than being presented as the same number.

Nothing in the upstream payload is modified — this project repackages what upstream ships.
