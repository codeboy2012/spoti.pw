spoti.pw v0.22.0

Released September 23, 2026

This release contains the spoti.pw v0.22.0 IPA builds based on the upstream project.

> ⚠️ Important: v0.21.1 is the last spoti.pw release to include Spoof Premium and Hide Ads. These features are not available in newer releases, so users who specifically want them should use v0.21.1.

> Important: spoti.pw is a UI tweak for Spotify on iOS. Sign the resulting build with your own certificate.

What's Included

This build is based on spoti.pw v0.22.0, which includes:

  • Apple Music-style animated album artwork on the lock screen when a track has no Canvas
  • Canvas playback as animated lock-screen artwork
  • Audio effects running on the mod's own engine; libjamesdsp has been removed
  • Glass search bar for finding tracks in playlists when pulling down
  • Genius lyric line meanings with artist-owned lines shown differently
  • Mod > Licenses now shows the mod license and full third-party licenses
  • Follow now uses the same glyph/checkmark behavior as Add to Library
  • Fixes for long settings notes being truncated
  • Fixes for Add to Library and Follow state behavior
  • Player menu and lyrics loading fixes
  • Playlist cover sizing and fade fixes while pulling down
  • Fix for the redesigned player being able to scroll upward

For the complete upstream changelog, see the https://github.com/skopevoj/spoti.pw/releases/tag/v0.22.0" rel="noopener nofollow ugc" target="_blank">[v0.22.0 upstream release.

Where this data comes from

Versions, dates, release notes and assets are read from the GitHub REST API by update-releases.pl and written into a generated data file at publish time. Nothing is typed in by hand, and no version number is hardcoded in any page.

Reading a release

  • Latest release — newest published release for that project
  • Prerelease — marked as a prerelease by its author
  • Upstream — belongs to a separate project, not to PwEevee
  • Cached data — GitHub was unreachable, so this is the last known-good value
  • No files — the release was published without attached assets, so there is nothing to download from it

Installable EeveeSpotify IPA variants are published separately by SideloadLabs and are listed on the downloads page, not in this timeline.
